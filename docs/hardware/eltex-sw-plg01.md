# ELTEX SW-PLG01

Умная розетка на Realtek RTL8720CF (AmebaZ2). Профиль: `profiles/eltex-sw-plg01.json`.

## Платформа

| | |
|---|---|
| Чип | Realtek RTL8720CF (AmebaZ2), Cortex-M33 |
| Флеш | 2 МБ |
| SRAM | 256 КБ |
| Плата ESPHome/LibreTiny | `generic-rtl8720cf-2mb-992k` |
| Secure boot | выключен |

## Распиновка

`GPIOA_x` = `PAx` в LibreTiny/ESPHome.

| узел | пин | примечание |
|---|---|---|
| реле | PA4 | активный высокий |
| кнопка | PA8 | активный низкий, подтяжка вверх |
| индикатор LED | PA7 | активный низкий, повторяет реле |
| измеритель SEL | PA9 | SEL=1 → напряжение, SEL=0 → ток |
| измеритель CF1 | PA2 | частота U или I (по SEL) |
| измеритель CF | PA3 | частота, пропорциональная мощности |

## Измеритель U/I/P

Чип — BL0937/HLW8012. Штатный компонент `hlw8012` на LibreTiny не считает
импульсы (прерывания на rtl87xx не работают), поэтому измеритель опрашивается в
C++ (`bl0937_poll.h`). Коэффициенты калибровки (значение = K × частота):

```
U[В]  = 0.133390392 * f
I[А]  = 0.010285907 * f
P[Вт] = 1.238737500 * f
```

## Датчик температуры

Зависит от ревизии платы (печатается в UART заводской прошивки: `hardware version: 2v3`):

| ревизия | термометр | I2C |
|---|---|---|
| HW 2v3 | LM75 распаян, заводская прошивка по нему защищает от перегрева | SDA — PA20, SCL — PA19 (прозвонено в issue #1, температура читается) |
| HW 3v0 | не распаян — I2C-адрес 0x48 не отвечает | — |

```yaml
i2c:
  sda: PA20
  scl: PA19
  scan: true    # в логе должен найтись 0x48
```

Где термометра нет, защиту имеет смысл строить по мощности/току (пример — в
`eltexplug-ota.yaml`).

## Раскладка флеша (992k, «SDK default»)

| раздел | смещение | размер |
|---|---|---|
| таблица разделов | `0x000000` | `0x1000` |
| system | `0x001000` | `0x1000` |
| calibration | `0x002000` | `0x1000` |
| bootloader | `0x004000` | `0x8000` |
| FW1 (ota1) | `0x00C000` | `0xF8000` |
| FW2 (ota2) | `0x104000` | `0xF8000` |
| kvs | `0x1FC000` | `0x4000` |

Шаг между слотами — `0xF8000`. При OTA новый образ пишется во второй слот (FW2);
таблица разделов не переписывается, поэтому образ собирают под раскладку `992k`.

## Точка доступа

В режиме настройки розетка поднимает точку доступа:

| | |
|---|---|
| SSID | `ELTEX-SW-PLG01-<последние 3 байта MAC>` |
| защита | WPA2-Personal |
| пароль | серийный номер в смешанном регистре (в QR-коде на корпусе) |
| адрес устройства в AP | `10.24.83.55` |
| порт провижининга | TCP 56684 |

Пароль удобно прочитать из QR: `python3 qrtool.py фото.jpg`.

## OTA

Розетка подписывается на `sys/cmd/<node_id>` и принимает `device_upgrade 0|<url>`,
затем качает образ по HTTP и пишет в FW2. После попытки отвечает в
`sys/event/<node_id>` строкой `status_resp <node_id>|<код>|0`: `1` — образ скачан,
`0` — скачать не вышло (формат команды при этом верный). Проводной дублёр —
`ATOTA=<url>` в AT-консоли по UART (TX/RX/GND).

События в `sys/event/*` розетка публикует с QoS > 0 и ждёт подтверждения — брокер
обязан отвечать PUBACK/PUBREC, иначе прошивка считает сообщения недоставленными
(`status not delivered!` в UART).

Проверенные сочетания: HW 3v0 + прошивка 2.3.0, HW 2v3 + прошивка 2.5.0.
